A PUNTA.

TCGym reúne el acceso de socios y flujos administrativos de un gimnasio. Tobías desarrolló frontend, backend y base de datos.

El repositorio público permite verificar una interfaz React, una API Express y persistencia MySQL. La aplicación conecta las funcionalidades de socios y los flujos administrativos en un mismo producto.

Qué incluye la aplicación

  • Registro y acceso por email o documento, con autenticación JWT.
  • Interfaces de socio y administrador, con comprobación de rol en endpoints administrativos.
  • Consulta de disponibilidad, creación y cancelación de reservas, y registro de asistencia.
  • Información de perfil, rutas de carga de rutina y foto, y cambio de contraseña.
  • Vistas administrativas de usuarios y turnos e interfaz con FullCalendar.

El desafío técnico

Coordinar las acciones de socios y administración sobre las mismas reservas. La implementación separa vistas React, rutas y controladores Express, y consultas SQL. La creación de turnos comprueba reservas existentes y cupos antes de insertar.

La implementación

Rutas protegidas en el frontend organizan el acceso a las vistas. La API verifica tokens JWT y roles administrativos en endpoints protegidos. MySQL persiste usuarios y turnos; la interfaz consulta disponibilidad y presenta el flujo correspondiente.
